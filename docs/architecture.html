AI 角色扮演对话应用

基于 Flutter 的本地 AI 对话引擎：长期记忆、关键词召回 + 事件图 BFS、三级级联、opencode 助手桥接。本文梳理各模块的实际数据流（不含未启用的预留扩展位）。

整体架构

分层：UI → ChatProvider（ChangeNotifier）→ 服务层（AiService / OpencodeService / ChatAgentStore / StructuredInputPromptComposer / StructuredOutputRegexParser / ChineseTokenizerService）→ 外部（LLM HTTP API、opencode、SharedPreferences）。
预留位：VectorMemoryService 留有 addMemoryEntry / searchSimilar 接口，但当前 searchSimilar 结果未参与 prompt 拼装。

三级记忆：短期 → 长期 → 超长期

每轮产生的 eventBrief 进入短期队列；短期累积到阈值后由 LLM 输出 summary 压缩入长期；长期再次累积后再次压缩入超长期。

关键参数

参数默认作用
summaryThreshold10短期 un-summarized 达到此值，触发 1→2 级联
ultraSummaryThreshold5长期 un-summarized 达到此值，触发 2→3 级联；设为 999 即禁用
maxShortTermEvents10进入 LLM 提示的短期事件数（取最新）
maxLongTermEvents1进入 LLM 提示的长期事件数（默认只取最新 summary；老 summary 经 2→3 cascade 进超长期）
maxUltraTermEvents2进入 LLM 提示的超长期事件数
maxRelatedEvents5关键词 + 事件图 BFS 召回返回的最大相关事件数（实际生效的召回路径）
searchDepth2相关事件在事件图里的 BFS 跳数

边关系与 LRU 排序

LLM 在响应里输出 relatedEventIds，代码限制最多 2 个 关联，避免边过密。LRU 评分会按关键词匹配、邻居事件权重、物品/设定关联权重综合打分。

远程连接（PC 上的 opencode）

Android 9+ 默认禁明文 HTTP，已通过 network_security_config.xml 放行；如走 HTTPS 反代，UI 有开关可切。

① Tailscale

PC + Android 各装 Tailscale 同账号；host 填 100.x.x.x，http。

② Cloudflare Tunnel

PC 跑 cloudflared tunnel --url http://localhost:4096；host 填 trycloudflare.com，https 勾上。

③ VPS SSH 反向隧道

ssh -R 0.0.0.0:14096:127.0.0.1:4096 user@vps；host 填 VPS 公网 IP。

已知限制 / 预留位

  • VectorMemoryService 留有 addMemoryEntry / searchSimilar 接口，searchSimilar 结果当前未参与 prompt 拼装（_buildPromptContact 没消费 weightedMemories）。addMemoryEntry 在每轮发送后入库是真实运行；vectorSimilarityWeight 设置保留但暂未生效
  • _simpleEmbedding 走字符级 codeUnit 累加 + 余弦相似度，非真语义；tflite_flutter 已在 pubspec 里但未挂接真模型（属未来升级点）
  • legacy events: EventLruBucket 仍在写但 prompt 只读 eventGraph，旧字段累积是冗余
  • SSH 模式在 OpencodeService._executeViaSsh 里直接返回"不可用"占位，HTTP 模式才是主路径
  • opencode 的 POST /session/:id/message 是同步等待；AI 任务长时（>300s）可能撞默认超时，可在设置里调
