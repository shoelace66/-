AI 角色扮演对话应用

基于 Flutter 的本地 AI 对话引擎：长期记忆、低成本 Agent 式事件召回、三级级联、opencode 助手桥接。

整体架构

分层：UI → ChatProvider（ChangeNotifier）→ 领域服务（EventRecallCoordinator / MemoryRecallService / 记忆级联与修订）→ 基础设施（AiService / OpencodeService / SQLite / SharedPreferences）→ 外部模型服务。世界书会进入正文 Prompt，但不参与事件召回。

三级记忆：短期 → 长期 → 超长期

每轮产生的 eventBrief 进入短期队列；短期累积到阈值后由 LLM 输出 summary 压缩入长期；长期再次累积后再次压缩入超长期。

关键参数

参数默认作用
summaryThreshold10短期 un-summarized 达到此值，触发 1→2 级联
ultraSummaryThreshold5长期 un-summarized 达到此值，触发 2→3 级联；设为 999 即禁用

低成本 Agent 式事件召回

召回采用固定的“计划 → 本地工具 → 观察 → 裁决”状态机，不允许模型自行循环。世界书和 knowledgeNodes 不进入该流程。

keyword / theme / relation] COLD{存在可用冷记忆?} CLEAR{强证据且候选明确?} PLAN[PLAN：最多 1 POST

只选择 E0..E11] OUT[相关事件进入正文 Prompt] EMPTY[0 POST：不追加冷记忆] INPUT --> L0 --> COLD COLD -- 否 --> EMPTY COLD -- 是 --> CLEAR CLEAR -- 是，0 POST --> OUT CLEAR -- 否 --> PLAN --> TOOL --> DECIDE DECIDE -- 是，累计 1 POST --> OUT DECIDE -- 否且有预算 --> JUDGE --> OUT DECIDE -- 否且预算耗尽 --> OUT

L0：无分词的完整词项匹配

  • 只索引事件 keywords/theme、物品/设定关系键和事件边
  • 只做 trim、ASCII 小写、全角转半角、空白与常见标点归一
  • 重叠词保留最长项；CJK 单字只允许整段相等；拉丁词要求字母数字边界
  • 不扫描 description/sourceDialog，不使用 jieba、n-gram、拼音、编辑距离或同义词

模型阶段：受限选择器

  • PLAN 输入最多 600 字当前输入、4 条历史和有上限的结构化目录
  • JUDGE 最多看到 12 张精简候选卡，最终选择不超过 5 个事件
  • 两阶段都使用严格 JSON、临时 ID 白名单、低温度、非流式和小输出上限
  • 独立召回模型失败时直接用本地结果，不切换昂贵主模型

协议与输入边界

阶段输入上限输出白名单
PLAN当前输入 600 字符；最近 4 条各 160 字符；目录 96 keywords / 32 themes / 48 relations；总计 3200 字符action、最多 8 个 K / 4 个 T / 4 个 R、recency、confidence
JUDGE最多 12 张候选卡；description 每条 140 字符；总计 4800 字符；不发送 sourceDialog最多 5 个冻结的 E ID 与 confidence

本地确定性评分

证据分值 / 规则说明
keyword每项 +120，最多 3 项最强直接证据
relation每项 +100，最多 2 项完整 belonging / setting 键
theme每项 +35，最多 2 项仅 theme 命中不能直接确认
证据组合命中至少两类 +25被两个以上直接种子连接再 +10
图扩展一跳 min(70, seed × 0.40)；二跳 min(30, seed × 0.18)多路径取最大贡献，避免环图堆分
节点状态summarized −10；needsReview −120invalidated 直接排除；待复核节点不自动确认
严格 POST 预算：每轮创建一个 RecallRequestBudget(maxPosts: 2)，在真正发送 HTTP POST 前扣减。失败请求和 404/405 兼容端点探测也计数；成功端点按 Base URL 缓存，减少后续探测成本。正文对话模型不计入这两个召回 POST。

远程连接（PC 上的 opencode）

Android 9+ 默认禁明文 HTTP，已通过 network_security_config.xml 放行；如走 HTTPS 反代，UI 有开关可切。

① Tailscale

PC + Android 各装 Tailscale 同账号；host 填 100.x.x.x，http。

② Cloudflare Tunnel

PC 跑 cloudflared tunnel --url http://localhost:4096；host 填 trycloudflare.com，https 勾上。

③ VPS SSH 反向隧道

ssh -R 0.0.0.0:14096:127.0.0.1:4096 user@vps；host 填 VPS 公网 IP。

已知限制

  • V1 依赖正文模型写入的结构化 keywords/theme 和关系键；别名未统一或事件漏标时不会用模糊字符算法猜测
  • 当前输入与最近 4 条有效消息都没有指向冷记忆的完整规范词项时，召回以 0 POST 结束；这是费用优先的明确取舍
  • 向量、Embedding、FTS、BM25 和故事内时间推断未启用；兼容字段 vectorSimilarityWeight 不参与 Agent 召回
  • legacy events: EventLruBucket 仍在写但 prompt 只读 eventGraph，旧字段累积是冗余
  • SSH 模式在 OpencodeService._executeViaSsh 里直接返回"不可用"占位，HTTP 模式才是主路径
  • opencode 的 POST /session/:id/message 是同步等待；AI 任务长时（>300s）可能撞默认超时，可在设置里调
