# AI Roleplay Chat v2.2.0

本版本完成了本地优先 AI 角色扮演应用的架构收口，并补齐 Android 发布产物。

## 主要更新

- 将聊天数据迁移到 SQLite v3，支持原子事务、旧数据迁移、分页加载与备份恢复。
- 增加会话时间线、检查点、分支、搜索、编辑、删除、引用和候选回复等完整对话能力。
- 增加记忆归档、召回调试、修订历史、事件图检索与世界书管理。
- 增加流式回复、取消生成、服务商配置与健康检查、Token/费用统计。
- 增加图片生成、图片缓存与画廊，以及可实际播放的 TTS 语音能力。
- 更新项目目标、实施路线图、架构图、CI 和测试覆盖。
